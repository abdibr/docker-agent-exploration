Shared rule: stdout carries protocol only; logs go to stderr; a startup banner declares the tool-safety policy (default restricted).

Decide in this order: roles in one config → sub_agents (ex04); catalog tool fits → catalog MCP (ex02); need exact self-authored tools → custom MCP server (ex03); peer is an MCP client → served MCP (ex05); agents must discover & hand off tasks → A2A (ex06); peer is the human's editor → ACP (ex07). Never: MCP refs on sub-agents (root only); MCP ≠ A2A; remote serving = network exposure.
Model note: every example runs on the built-in ollama provider → gemma4:latest on the local daemon. Cloud glm-5.3-flash:cloud appears only in pre-approved smoke runs — the swap is one model: line.
